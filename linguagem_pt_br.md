# Guia de linguagem — Português

O projeto usa português como idioma principal. Termos técnicos importantes aparecem com a expressão original em inglês na primeira ocorrência.

| Inglês | Português |
|---|---|
| Dataset | Conjunto de dados |
| Target | Variável-alvo |
| Feature | Variável preditora / atributo |
| Exploratory Data Analysis (EDA) | Análise Exploratória de Dados |
| Preprocessing | Pré-processamento |
| Feature Engineering | Engenharia de atributos |
| Train/Test Split | Separação entre treino e teste |
| Cross-Validation | Validação cruzada |
| Precision | Precisão |
| Recall | Capacidade de identificar os positivos reais |
| F1-score | Equilíbrio entre precisão e recall |
| ROC-AUC | Área sob a curva ROC |
| Confusion Matrix | Matriz de confusão |
| Feature Importance | Importância das variáveis |
| Outlier | Valor extremo / observação atípica |

Os nomes das colunas do dataset permanecem em inglês para que o código funcione diretamente com a base original.
